# 2026-10-02 更新审计与修复

审查范围为 `8933a431..4a3685e9`，覆盖 10 月 1—2 日的更新，重点复核 DijiangV2 接口适配、角色同步、森空岛、路线、AI 助手与依赖变更。工作区开始时无未提交改动。

## 高风险依赖

Expo 工具链间接使用的 node-forge 1.4.0 存在 RSA PKCS#1 v1.5 嵌套 DigestAlgorithm 校验漏洞，见 [GHSA-86w9-cpqp-85rv](https://github.com/advisories/GHSA-86w9-cpqp-85rv)。这是依赖公告的严重度，未证明地图业务存在直接可利用的签名校验入口。

目前没有已发布修复版本。已采用上游 [PR #1152](https://github.com/digitalbazaar/forge/pull/1152) 的元素数量检查，注册到 `pnpm-workspace.yaml` 并写入锁文件。正常签名和恶意嵌套元素回归检查通过。版本仍为 1.4.0，因此 `pnpm audit` 会继续报该公告；不能把扫描告警当作已清零。补丁说明位于 `patches/README.md`。

## 中风险与功能回归

1. **V2 第三方登录没有初始化 state/nonce：已修复。** `apps/web/src/components/features/user/login/third_party.tsx` 原来直接打开硬编码供应商 URL，回调会被 V2 后端拒绝。现在统一从后端 `/auth/oauth/{provider}/authorize` 开始，并接住后续登录失败的 Promise。
2. **刷新队列错误处理不完整：已修复。** `packages/map-service/src/service/server.ts` 原来在 refresh 返回 5xx 时强制登出，已登录状态下的错误密码登录也会触发刷新，等待刷新完成的 POST 又丢失 JSON Content-Type。现在临时故障保留会话，登录失败直接返回，排队请求保持 JSON header。
3. **远端空标记漏算本地差异：已修复。** `packages/map-service/src/service/skland_sync.ts` 不再跳过 `marked: []` 的地图，本地已标记点仍进入差异列表。
4. **超过 2000 个标记时静默丢项：已修复。** 同一服务按总点数分批推送并汇总结果，后端配套拒绝超限单批，避免截断后报成功。
5. **定位旧请求恢复过期标记：已修复。** `apps/web/src/services/player_position_store.ts` 将请求绑定到轮询代次，停止或切换角色后丢弃旧响应，新角色也不会被旧请求阻塞。
6. **跨地图撤销错点：已修复。** `packages/map-service/src/service/data/map/route_transform.ts` 原来把再次进入同一地图的点塞回旧段，导致撤销顺序与点击顺序不同。现在按连续点击顺序建段。
7. **AI 取消后仍可能执行工具：已修复。** `packages/map-service/src/service/ai/assistant.ts` 拒绝迟到的结果与工具调用，旧请求结束不会清掉新请求的 running 状态，取消的工具消息也有完整回执。
8. **AI 最终回答丢失于上下文：已修复。** 同一文件现在保存非工具的最终 assistant 消息，后续问题可以引用先前回答。
9. **原生端测试类型检查失败：已修复。** `apps/native/components/ui/__tests__/entity-info-sheet.test.tsx` 改用 `@jest/globals` 后，`requireActual` 的默认返回类型变为 unknown。现显式提供真实模块类型，并在原生 package.json 增加 typecheck，使根目录检查不再跳过原生端。
